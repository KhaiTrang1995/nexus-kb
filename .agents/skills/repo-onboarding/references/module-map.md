# Module Map

- Root `README*.md`: public project overview and localized summaries.
- `docs/architecture.md`: source-of-truth architecture.
- `AGENTS.md`: repository-wide agent and contributor baseline.
- `.rules`: optional AI guidance service rules.
- `.claude/`: Claude Code project configuration, commands, and rules.
- `.codex/`: Codex project configuration, agents, rules, and skills.
- `.agents/`: shared project skills for local agent tooling.
- `.hermes/`: Hermes runtime template; local logs, sessions, auth, and private memory must not be committed.
- `qdrant-multi-node-cluster/`: runnable Python and Docker Qdrant demo.
