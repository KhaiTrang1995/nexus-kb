Implemented Surface

Each area is intentionally scoped for local verification and clean service boundaries.

INGEST

Markdown and Obsidian Pipeline

Parses frontmatter, tags, wikilinks, headings, mime data, and section-aware chunks before embedding.

RETRIEVE

Hybrid Search

Combines Qdrant vector results with PostgreSQL metadata joins, lexical reranking, snippets, filters, and graph context.

GOVERN

Audit and Review

Records sensitive workflow events and supports approve, reject, and modify review actions with mock reviewer RBAC.

MCP

Confluence Bridge

Provides source discovery and document read tools with user-context authorization, disabled mutations, and redacted structured errors.

GRAPH

Knowledge Graph Builder

Builds entities and relationships from approved chunks, merges duplicates, and stores confidence plus provenance.

LLM

Gateway Slice

Centralizes model routing, prompt categories, cache behavior, retry handling, telemetry, and provider abstraction.

Run Locally

Commands match the current Python package layout.

1. Install dependencies

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

2. Start storage and migrate

docker compose up -d
alembic -c infrastructure/alembic.ini upgrade head

3. Start FastAPI

$env:PYTHONPATH="packages/shared-contracts;packages/vector-client;workers/document-parser;workers/graph-builder;services/nexus-api"
uvicorn nexus_api.main:app --reload

4. Verify

python -m pytest -q
$env:NEXUS_KB_RUN_LIVE_TESTS="1"
$env:POSTGRES_DSN="postgresql://nexus:nexus_dev_password@localhost:5432/nexus_kb"
python -m pytest tests/test_live_integration_scaffold.py tests/test_live_graph_repository.py -q
